# Задача №2. Длинная арифметика

## Задача
Реализовать длинную арифметику для целых чисел с операциями сложения, вычитания,
умножения и целочисленного деления.

## Комментарии к задаче
Длинная арифметика уже реализована в классе int. Тем не менее, предлагается
задаться некоторым основанием системы счисления M и максимальной разрядностью в
M-ричной системе счисления N и реализовать перечисленные выше операции для представлений
длинных чисел в этой системе счисления.
