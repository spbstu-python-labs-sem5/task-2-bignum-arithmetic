# Задача №2. Длинная арифметика

## Задача
Реализовать длинную арифметику для целых чисел с операциями сложения, вычитания,
умножения и целочисленного деления.

## Комментарии к задаче
Длинная арифметика уже реализована в классе int. Тем не менее, предлагается
задаться некоторым основанием системы счисления M и максимальной разрядностью в
M-ричной системе счисления N и реализовать перечисленные выше операции для представлений
длинных чисел в этой системе счисления.

## Решение
Прописали класс `BigInt`, который хранит целое число произвольной длины в системе счисления
по основанию `base` (по умолчанию - 10). Поля:
- `digits` - список цифр, младшая - первая;
  Например, число `1234` при `base=10` хранится как `[4, 3, 2, 1]`;
- `sign` - знак: `+1` или `-1`.
- `base` - основание системы счисления (`>= 2`).
Такое представление удобно тем, что все арифметические операции работают
с младших разрядов.

- **Сложение** (`+`) - поразрядно с переносом. Если знаки разные,
  вычитаем меньший модуль из большего и берём знак большего.
- **Вычитание** (`-`) - через `self + (-other)`: работает от сложения, просто инвертируем знак у второго числа.
- **Умножение** (`*`) - каждую цифру одного
  числа умножаем на каждую цифру другого и складываем результаты со сдвигом.
- **Целочисленное деление** (`//`) - длинное деление. На каждом шаге
  берём очередную цифру делимого, добавляем к текущему остатку и
  подбираем цифру частного **бинарным поиском** по `[0, base-1]`.

Все операции работают с модулями, а знак результата ставится в конце.

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/spbstu-python-labs-sem5/task-2-bignum-arithmetic
cd task-2-long-arithmetic
```

### 2. Создать виртуальное окружение
```bash
python3 -m venv .venv
source .venv/bin/activate # Linux / macOS
# .venv\Scripts\activate # Windows
```

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

## Тесты
```bash
pytest -v
```

Тесты покрывают:

- конструкторы (`int`, `str`, список цифр, ошибки);
- все четыре арифметические операции на положительных, отрицательных
  и нулевых операндах;
- работу в разных системах счисления;
- сравнения (`==`, `<`, `<=`, `>`, `>=`);
- унарные операции (`-a`, `abs(a)`);
- деление на ноль.
